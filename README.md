
# Yaning Liu — personal academic website

A responsive static website for GitHub Pages. The HTML at the repository root is ready to publish; no installation or build is needed on the server.

## Updating content

- `content/profile.json`: roles, contact details, and profile links.
- `content/publications.json`: the complete bibliography. Each record contains its authors, year, publication type, venue, URL, and research topics. Recent records also contain DOI and source links. Use `year: null` only for genuinely undated work, and identify preprints with `type: "preprint"`.
- `content/pages/*.html`: page content, including teaching, students, grants, and resources.
- `templates/base.html`: common navigation, page metadata, and footer.
- `assets/site.css` and `assets/site.js`: shared visual design, navigation, and publication filters.

After editing source content, regenerate and check the HTML with Python 3.10 or later:

```sh
python scripts/build_site.py
python scripts/check_site.py
```

Both scripts use only the Python standard library. Commit the regenerated root HTML along with the content changes. The bibliography download, sitemap, and old-homepage redirect are generated by the same build.

## Local preview

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8765/index.html`. Stop the server with Ctrl+C when finished.

## Design and behavior

- Warm paper, deep green, and muted gold; system fonts with no external font or framework requests.
- Responsive layouts, accessible navigation, skip link, visible keyboard focus, and reduced-motion support.
- Every publication is present in HTML and remains readable without JavaScript.
- Publication search, year, research-area, and type filters support shareable URLs; each page has a print layout.
- Existing page URLs are retained. `index_old.html` redirects to the current homepage.
- A BibTeX download, page descriptions, canonical links, social metadata, and sitemap support discovery and reuse.

Content was refreshed in October 2026 using the faculty profile, Google Scholar, publisher records, and the user's CV. See `content/SOURCE_NOTES.md` and `content/PUBLICATION_SOURCES.md` for provenance and citation corrections.

The source CV and local QA files are excluded from the public repository. Deployment uses the repository's existing GitHub Pages setup after changes are committed and pushed.
